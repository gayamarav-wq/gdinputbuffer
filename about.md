# Predictive Input Buffer

**A practice and accessibility assist.** Press a little early; the mod holds the press for a few physics ticks and fires it on the first tick you can actually act (landing, touching an orb).

**Please turn it off (mode 1) for any run you submit for verification.**

## Modes
1. **Off** - vanilla input (default)
2. **Low** - up to 4 ticks
3. **Medium** - up to 6 ticks
4. **High** - up to 10 ticks

A tick is one physics step. One press fires at most once, and an expired press is never fired.

Change the mode in the settings, with the pause-menu button, or with the hotkey (default Shift+B).
